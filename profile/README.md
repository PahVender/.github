# PahVender

**Herramientas comerciales para simular, entender y operar comisiones del portafolio Pah Venture.**

PahVender es el espacio de habilitacion comercial para vendedores y equipos que trabajan con productos de Pah Venture, incluyendo Matrixmd, PahCertificar, PahFacturar y planes empresariales negociados.

## Que Hacemos

- Simulacion de comisiones para ventas anuales y mensuales.
- Modelado de renovaciones, ventas cruzadas y valores negociados.
- Seguimiento de metas mensuales, trimestrales y anuales.
- Herramientas internas para alinear incentivos comerciales del portafolio Pah Venture.

## Para Quien Es

PahVender esta orientado a equipos comerciales, lideres de ventas y operaciones internas que necesitan calcular escenarios de comision antes y despues del cierre de ventas.
